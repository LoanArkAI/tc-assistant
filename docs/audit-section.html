Your TC Assistant

Your transaction checklists and setup

Your Claude TC Assistant is set up for Kase. Every file it opens follows the Kase checklist for that transaction type, and every document is named exactly as its checklist item — the SkySlope slot name, with no property address.

Setting it up

  1. Download and install the plugin. Download the TC Assistant (tc-assistant.zip). Then in Claude (desktop app or claude.ai): Customize → Plugins → Add → Upload plugin, and choose that file.
  2. Connect your accounts in Claude: Gmail, Google Calendar, Google Drive and DocuSign.
  3. Run setup. Tell Claude “set up the TC assistant”. It connects Follow Up Boss and asks for anything it still needs.
  4. Texts (optional, on your Mac). Unzip the same tc-assistant.zip, run mac-tap/install.sh with your TC Assistant folder in Google Drive, allow Full Disk Access for Python, then tell Claude “set up texts”. It only reads texts with the work contacts Claude lists from your deals, and it never sends a message.

Kase checklists

All 18 checklists, imported from the Kase master checklist workbook. Claude picks the one that matches the side and property type when it opens a file.
